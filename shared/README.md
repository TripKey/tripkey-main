## Shared

TripKey의 공용 문서와 데이터베이스 리소스를 모아둔 영역입니다.

## 구성

- `docs/schema.sql`: 현재 기준 DB schema 참고본
- `docs/migrations/`: 순차 적용 가능한 DB migration SQL
- `docs/TripKey_PRD_v3.2.md`: 제품/UX 기준 문서 (현재 문서 버전 v4.0)
- `docs/TripKey_SA_DS_v3.3.md`: 시스템 아키텍처 및 데이터/API 계약 문서 (현재 문서 버전 v4.0)
- `docs/TripKey_Screen_Impl_Spec_v1.0.md`: 화면 단위 구현 스펙 (현재 문서 버전 v2.0)
- `docs/Card_Level_Notes_Parsing_Changes.md`: card-level notes 파싱 변경 기록
- `docs/dev-api-e2e-2026-05-12.md`: dev API E2E 실행 기록
- `docs/TripKey_Changelog_v3.2_to_v3.3.md`: 문서/스펙 변경 기록

코드 변경으로 API, DB schema, 카드 상태 모델, 화면 정책이 달라지면 관련 문서와 changelog를 함께 갱신합니다.
